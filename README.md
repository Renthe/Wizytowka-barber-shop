
# Opis projektu
projekt przedstawia stronę wizytówkową salonu fryzjerskiego "Barber Marzeń" strona została wykonana przy użyciu HTML CSS oraz JavaScript zawiera sekcje prezentujące ofertę cennik informacje o salonie oraz interaktywny formularz rezerwacji wizyty strona dostosowuje się do ekranów urządzeń mobilnych oraz spełnia podstawowe wymogi dostępności wcag

# czego sie nauczylem 
robienie responsywnych stron:Jak pisać zapytania @media w CSS układać elementy za pomocą Flexboxa i Grida oraz jak chować/pokazywać mobilne menu w JS 

podstaw dostępności wcag Łączenia ustawiania widocznego :focus żeby po stronie dało się łatwo skakać klawiszem Tab.

pracy z git i githubem Tworzenia commitów i ogarnięcia podstawowych komend add commit push

# Trudności podczas pracy
błędy w js na początku skrypt wywalał si, bo w HTML brakowało przycisku z odpowiednim id musiałem też chwilę zastanowić sie dlaczego formularz od razu przeładowuje stronę i jak to zablokować
responsywnością trochę walki było iż nigdy tego nie robiłem a także z tym żeby obrazki i karty usług nie wychodziły za ekran na telefonie 

ogarnięcie gita na początku miałem problem z ogarnięciem samych komend i jak to wszystko działa w gicie bo wcześniej z niego nie korzystałem ale po chwilu załapałem jak co dziala
